# The wire contract, as semantic values and the exact bytes they must become.
#
# Hand-authored: the hexadecimal was produced by a third implementation (Python `struct`),
# not by either codec under test, so neither Rust nor Elixir can pass by reproducing its own
# mistake. A fixture generated from the code it validates proves only that the code is
# consistent with itself.
#
# `check_wire_bytes.py` beside this file re-derives every record, decodes it back, and refuses
# every `reject` line *for the reason stated here* using its own decoder. It is run by
# `./build.sh check`, so that independence is re-established on every gate rather than being a
# claim about how the file was written once. It verifies and never writes: a generator committed
# beside its output invites regenerating instead of hand-authoring, and the independence is gone
# at that moment.
#
# Little-endian throughout. Every record begins with a u8 discriminant, and the field order,
# widths and signedness below are the contract:
#
#   1 position  : topology_version u64, space u128, x i32, y i32         (33 bytes)
#   2 ownership : entity u64, region u32, epoch u64                      (21 bytes)
#   3 transfer  : transfer u64, transition u8, from_region u32, to u32    (18 bytes)
#
# The topology version is the manifest's content hash -- sixteen hex characters, exactly u64 --
# so a position can *name* a release rather than a bare counter. It was a freely constructed u32
# with no relationship to any artifact.
#
# Naming is not proving. Any u64 encodes here and any sixteen lowercase hex characters parse, and
# neither can tell whether the release was ever compiled: only resolving against the loaded one
# can, and that is `LoadedTopology::resolve` / `Arena.World.Topology.resolve/3`. A version on the
# wire is a claim to be checked, not a checked claim.
#
# A space id is 128 bits because not every space is compiled: `W-0104` mints one per live
# dungeon instance at runtime, from whichever region is asked, and a narrower id would need a
# central allocator or hand-managed ranges to stay unique. A region id stays 32 bits because a
# region is a unit of authority over compiled content, not something minted per player action.
# It is not yet allocated by anything: W-0097's manifest emits spaces, geometry, maps and
# origins and contains no regions, so the region ids here are hand-authored and W-0125 owes a
# stable allocator.
#
# Transition discriminants: 1 seam, 2 door, 3 portal, 4 teleport, 5 instance. 0 is not a
# kind -- a zero byte is what an uninitialised field looks like, and it must not decode as
# "geographic seam", the one kind that means a player crosses without noticing.
#
# Identities are distinguishable even at equal numeric value: the `1 2 3 4` cases exist so an
# implementation with two same-width fields transposed fails instead of round-tripping.
#
# Both languages must, for every line: encode the semantic value and match the bytes, decode
# the bytes and recover the value, and refuse every `reject` line for the stated reason.
#
# columns: <record> <fields...> = <hex bytes>
#          reject <hex bytes> <truncated|oversized|unknown-record|unknown-transition>
